# 紹介文の文体規範

**2026-08-04 の全面改訂。** それ以前の紹介文は「古風で硬い」という理由で全 365 本を書き直すことになった
（ユーザー指示）。ここに書いてあるのは、その書き直しで実際に直した型だけです。
**執筆・検証・修正のどの段からもここを見ます。**

見本は `data/emperor-profiles.json` の `qin-shi-huang`（2026-08-04 にユーザーが承認）と
`qin-er-shi`（同じ日に同じ手順で書いたもの）。**迷ったらこの2本を読んでから書いてください。**

## 目指すもの

**歴史の読み物として、一度読んで頭に入る文章。** 読者は専門家ではありません。
文末は だ・である 調。原文の語をそのまま持ち込まず、**内容を理解して自分の言葉で書きます。**

## 1. 漢文訓読調の語をやめる

書き直しで実際に潰した言い換えです。**同じ型を自分の原稿で探してください。**

| 使わない | 使う |
|---|---|
| 没する・崩御する | 亡くなった・死去した |
| 諫める | 訴える・意見する |
| 誹る・讒言する | 非難する |
| 上書する | 申し出る（官の正式な行為なら「上奏する」でよい） |
| 逡巡する | ためらう |
| 刑殺をもって威とする | 刑罰で人をおどして威を保つ |
| 所在を隠す | どこにいるかを隠す |
| 〜に傾倒する | その人が実際に何をしたかを書く |
| 恣にする | 好きなようにふるまう |

**古代の器物に現代の語を当てない**のも同じ原則の裏側です。
陵墓の「機相灌輸」を「機械で流し」、「機弩矢」を「自動で射る弩」と書いて差し戻しになりました
（→「からくりで巡らせ」「射る仕掛けの弓」）。

## 2. 人物の内心を断定しない

**最も重要な規約です。** 本人にしか分からないことを、史実であるかのように書かない。

> ✗ 統一を果たした政は、「王」という称号では自分の功績に釣り合わないと考えた。
> ○ 統一を果たした政は「いまの名号のままでは功業を称え、後世に伝えられない」として、群臣に新しい帝号を議論させた。

直すのは**言い換えではなく置き換え**です。内心を消すのではなく、**史料に載っている発言・詔・行動に差し替える**
（上の例は本紀の詔「今名号不更、无以称成功、传後世。其议帝号」）。

**史料そのものが心情を書いている場合は、その範囲で書けます。**
「始皇悪言死、群臣莫敢言死事」があるので「死を口にするのを嫌い」は書けます。
一方、そこから「死を恐れるあまり判断を誤った」へ進むと、また断定になります。

同じ型として、**原文が並べているだけの2件を「〜のため」でつながない**（因果の捏造）。

## 3. 通説と史書の食い違いを本文に書く

**紹介文がネット上の要約と違う価値を持つのはここだけです。** 原典に当てて通説とずれた点は、
黙って正しいほうを書くのではなく、**ずれ自体を1文で示します。**

> この2つの事件を合わせて後世「焚書坑儒」と呼ぶが、『史記』に「坑儒」の語はなく、埋められたのも儒者に限らない学者や方士たちである。
> なお、この墓の東で出土している兵馬俑には、史書はひとことも触れていない。
> 「阿房宮」という呼び名も地名から来た仮のもので、できあがったら別の名を選ぶつもりだったという。

書く価値があるのは、**読者が別のところで見聞きしている可能性が高い通説**とのずれです。
史料内部の細かな異同（どの列伝が何と書くか）は `basis` に置いて本文に出しません。

## 4. 表記は日本での通りを優先する

底本の字体より、**日本の読者が知っている形**を採ります（『史記』の底本は「徐巿」ですが本文は「徐福」）。
**採らなかったほうは `basis` に残します。** 検証段が毎回同じ差分を挙げるのを防ぐためです。

固有名詞の読みは `data/name-readings.json` に載っていればそれに従います（→ ルビの節）。

## 5. 引用符「」に入れてよいもの

**2026-08-04 改訂。** 括弧に入れてよいのは次の2つだけで、**どちらも `claims` に対応する原文句が
無ければ書けません**（それが唯一の条件であり、唯一の担保です）。

1. **史料が直接話法（「〜曰」）で載せている発言**
2. **書物の記述を引くとき** — 『史記』は「生まれて政と名づけられ、姓は趙氏」と記している／
   『史記』は同じ巻の末尾に「二世は12歳で立った」とも書いており、…

```
長男の扶蘇が「天下が定まったばかりで遠方の民はまだなじまず、学者はみな孔子を規範として
いるのに、重い法で縛れば世が乱れます」と訴えると、…
```

**ここまでです。**

- **地の文の言い換えを「」で括らない。** 陵墓の描写のような叙述は括弧に入れず地の文で書く
  （括弧に入れると、照合済みの引用のように見えます）
- **史官の評（「評曰」「論曰」「太史公曰」）を地の文にも「」にも混ぜない。**
  書くなら「史書の評は〜と書く」と主語を立てる

改訂前は「原文の和訳を『』で括って引かない」（2026-08-01 決定）でした。**緩めた理由**は、
括弧を外すと会話がすべて間接話法の要約になり、読み物として平板になるためです。
2026-08-01 の決定が守っていたのは「和訳は誰も検証しない」という一点なので、
**担保を `claims` へ移して同じものを守っています。**

## 6. 時制・主語

- **過去形にそろえる。** 歴史的現在（「継ぐ」「定める」「上奏する」「倒れる」）を混ぜない。
  混在は読者が時間軸を見失う原因になります
- **節や段落の頭で主語を省かない。**「前259年の正月、趙の都・邯鄲で生まれた」→「政は前259年の正月、…」
- **動作の主体を落とさない。**「察知されて未遂に終わった」→「政はこれを察知し、暗殺は未遂に終わった」
  （本紀「秦王覚之」）

## 7. 構成と字数

| 欄 | 役割 | 字数（**ルビを剥がした長さ**） |
|---|---|---|
| `lead` | **概要**。ヒーロー内に出る。人物の一生を1段落で見通す | 150〜250字（ゲートは 70〜260） |
| `body` | 「人物紹介」節。**節見出しを立てて時系列で追う** | 100〜2400字・任意 |
| `description` | `<meta>`・JSON-LD | 100〜140字・**平文（ルビ禁止）** |

- **`lead` の第1文は定義文**（「〜は、…の皇帝である」）。そこから即位・事績・最期までを含める
- **`body` の節見出しは行頭 `## `**、段落と同じく空行で区切る。4〜6本が目安
- **見出しは内容を指す名詞句にする。** 差し戻しになった実例が2つあります —
  「六国をたたむ」（口語的な比喩・→「六国の統一」）と「「群盗にすぎません」」
  （**本文中の発言をそのまま見出しにした**・→「反乱の広がり」）。
  後者はこの規約を書いた当人が同じ日に破っており、**自分で書いた原稿では見出しの型が見えません。**
  検証段が見る4点に入っています
- **1つの節に話題を1つ。** 中身が変わったら節を割る（郡県制と度量衡が「「皇帝」という称号」の節に
  ぶら下がっていて、独立した節「中央集権化と規格の統一」に分けました）
- **字数を埋めない。** 確かなことが少ない人物は短く終える。事実を1つ足すたびに誤りうる面が1つ増えます
- **上限に当たったら節を1つ落とす。句を削らない。** 2026-08-04 に胡亥を8回削って上限へ収めたところ、
  落ちたのは埋め草ではなく内容でした（将閭の発言から1句・王を名乗った者の記述・魏咎）。
  **何を落としたかは `basis` に1行書く**（削った跡は本文からは見えません）

## 8. 従来からの規約（変わっていないもの）

- **敬称・賛辞・主観的評価を書かない**（「名君」「暗愚」「英明な」）
- **`諱は◯` に姓を入れない**（「諱は劉盈」ではなく「諱は盈」）
- **回数8項目の集計値を書かない**（「改元3回」「反乱8件」）。個々の事件名は書く。在位年・年齢は書く
- **年譜形式にしない**
- **ルビは総ルビ**（`lead`・`body` の漢字すべてに `｜親文字《ルビ》`。`description` は平文）
