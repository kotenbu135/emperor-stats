秦・漢の章（105人）で 2026-08-19 にユーザーの「概ね良い」まで到達した形を、
続く章を同じ品質で作るための規範として書き残した。**2026-08-20 に第10章「清」まで
そろい全時代で完結**（365人全員がいずれかの章に居る）。この規範は今後の訂正・
人物の増減のときに引く。ビルドが落ちる契約は [site/AGENTS.md](../../site/AGENTS.md) の「系譜図」節が正。
取り下げた2版の失敗（2026-07-24・2026-08-17）は SITE_DESIGN.md と Issue #174 に残っている。
見た目の見本は `docs/site-design/kinship-refs/`（**形の見本は B = UsefulCharts**。
A = ハプスブルクは肖像カードと章ナビの見本）。

## 1. 図の文法 — 「一般的な家系図のつなぎ方」（2026-08-19 ユーザー指示）

- **夫婦は必ず隣に並べ、カード中央の高さの横棒で結ぶ。** 複数婚は鎖
  （呂雉—高帝—薄姫）。**結び目の点は描かない**（黒点は 2026-08-19 に廃止）
- **子は夫婦の横棒から T 字に下ろす。** 下ろし点は夫婦の間（横棒の上ならどこでも
  よい — 中央に固定しない）。兄弟は1本の幹 → 1本の横バス → 各自へ垂下の櫛にする
- **片親しか確定していない子は親のカードの真下の縁から直接下ろす**
- 線種（実装は `chapter-flow.tsx` の `EDGE_STYLE` が唯一の正・凡例はそこから導出）:
  | 線 | 見た目 |
  |---|---|
  | 夫婦の横棒・実の親子 | 実線 1.9px |
  | 実母だけ確定 | 破線 5 4 |
  | 養親 | 一点鎖線 12 4 2 4 ＋ 線上に「養母／養父」ラベル |
  | 実父の異説（呂不韋型） | 点線 1 4・幅2 の夫婦横棒（記号は重ねない） |
  | 継承（受禅・簒奪・復位・推戴・自立・内禅） | 朱の破線 6 4 ＋ ラベル ＋ 矢印（20px・先が次の皇帝） |
- **継承のラベルは矢先の人（次の皇帝）がどう即位したかの語で統一する**（2026-08-21
  ユーザー指摘「どっちが簒奪したのか分かりにくい」への対応）。「禅譲」だけ根元の人
  （譲った側）の行為で視点が混ざっていたので「受禅」（/database の即位経路と同じ語）。
  凡例の継承の行にこの読み方の1文を出す
- **引かない線**: `enthroned`（擁立）・`hereditary`（世襲・家系の線と重複）・
  `remote-ancestor`（段が飛ぶ）。親子で既に結ばれた2人の継承線も引かない。
  **例外**: 遠祖しか判っていない人が、これを引かないと**章内に線が1本も無くなる**
  ときだけ引く（西燕の慕容永 — 実父が史料に無く祖父＝慕容運まで。養親と同じ一点鎖線＋
  線上に続柄ラベル「祖父」。曾祖父しか判らない慕容詳は簒奪の線で章につながるので不発）
- **相手が3人以上いる人は、夫婦の鎖に入れるのは2人まで**（鎖の両隣しか枠が無い）。
  3人目以降の union は「父の実線＋母の破線」の直線2本に落とす。残す2人は (1) 子の多い
  union、(2) **相手が他の誰とも鎖を持たない側**、(3) 子の年が古い側の順（慕容皝の3人では
  公孫氏〔子＝慕容徳〕を落とした）。(2) が要るのは唐の太宗（長孫氏・武則天・楊妃）—
  武則天を鎖に残すと 長孫氏—太宗—武則天—高宗 と伸び、高宗が実の両親と同じブロックに
  入って親子の線が引けない。**demote された union に子が無いとその婚姻は図から消える**
  （太宗×武則天がこれ。生成ログが warn で名指しする — 黙って消えたのではない）
- **皇帝は「章内に線が1本も無い」でも図から外さない**（隋末・唐末の群雄8人 — 家族も
  引ける継承も無い）。線ゼロの1人ブロックのまま、小成分の時代合わせで在位年の段に置く
- **カード**: 皇帝 = 112×164（上半分は肖像。無い人は政権色の印章面＋姓1字）＋政権色帯。
  **名前が 112px に入り切らない人だけ、そのカードの幅を個別に広げる**（レイアウト
  スクリプトの `widthOf` — ふりがな ON の rt の幅も勘定する。2026-08-21 ユーザー指示
  「名前が長い人物は箱の大きさを調整して…にならないようにする」。それまで許容していた
  少数の切り詰めはこれで全廃・幅の一律拡大はしない）。
  **皇帝の名前はサイト共通の `display-name.ts` を通す**（通用名＋補助名の諱。
  commonName を生で出すと一覧と割れる — 「一覧では高祖なのに系譜図では高帝」
  2026-08-19。レイアウトスクリプトから Node の type stripping で .ts を直接 import）。
  親族 = 名前と年の帯だけ（48px・名前に補足がある人は62px）・男女2色。
  高さ3種は 2026-08-19 にふりがなと「第N代」の行ぶん 140/38/50 から広げた値。
  **名前にはふりがな**（Issue #20・サイト共通のトグルで ON/OFF）— レイアウト JSON は
  平文のまま持ち、ルビ記法は chapter-page（サーバー側）の `rubyOf` が付ける。
  **系譜図に人を足したら `data/name-readings.json` に読みを足す**（未登録はビルドが落ちる。
  親族の名前は emperors.json に無いので、皇帝追加のチェックリストだけでは拾えない）。
  **皇帝カードには名前の上に「政権名 第N代」**を出す（2026-08-21「どの王朝の人物か
  知らないと理解しづらい」への対応。政権の短い名前は `site/src/lib/kinship/regime-label.ts`
  の `REGIME_LABEL` が唯一の正）。代数の出どころは `reigns[].dynastyOrder` で、**数値が
  入っている在位だけ**（**在位順から推論しない** — Issue #69）。2026-08-20 に 89/89政権を
  読み切ったので `dynastyOrderSurveyed: false` の政権はもう無く（Issue #24）、
  「調べた上で歴代に数えない」と判定した並立・僭称の21在位は**政権名だけ**になる。
  復位は在位ごとに別カウントなので「第2・4代」（晋恵帝）のように並べる。
  **皇帝を称さなかった歴代君主**（kinship.json の `inclusionReason: ["ruler", …]`・
  ヌルハチ・チンギス〜モンケ・前涼の張氏9代など）の親族カードにも同じ行を出す —
  出どころはレイアウトスクリプトの `RULER_ORDINALS`（emperors.json の欠番との重複を
  assert で突き合わせる。行の高さ +14px）。**この表の人物は線が1本も無くても図から
  外さない**（蘭汗・段随 — 外すと代数が飛んで見える。皇帝の線ゼロ許容と同じ線）。
  **カードの名前の行はドラッグで選択してコピーできる**（2026-08-21。`nopan select-text` で
  パンを名前の上だけ止め、選択で終わったクリックは遷移しない。実測は
  `tools/kinship-select-test.mjs` の4点）。
  **親族の左端 4px に「その家の政権」の色**を立てる（家族の線で最寄りの皇帝から写す。
  帯そのものを政権色にすると男女の区別と白文字 4.5:1 が崩れるので縁の1本にとどめる）
- **収録**: 章（eraId）の皇帝＋親族＋**客人**。**章内に線が1本も無い人物は図から外して**
  `generatedFrom.dropped` に記録する。章をまたぐ親子は `crossEra` に記録
- **客人**（章の eraId でないが出す人物・`CHAPTERS` の `guests`）は4種類だけ:
  (a) **禅譲の前帝**（後漢の献帝→魏。「だけ」入れる — 前帝の家族は連れて来ない）、
  (b) **前の章で「線が1本も無い」として外した親**（袁逢・劉弘。子がこの章にいる）、
  (c) **章を持たない時代の人物**（近代の袁世凱と父2人 — 皇帝1人のために第11章を
  立てず最終章「清」に出す。2026-08-20・清の皇室と線は無い独立成分）、
  (d) **章の入口の皇帝の実親**（東晋の元帝の実父司馬覲・実母夏侯光姫。前の章に
  線を持って出ている人でも、禅譲の無い章替わりでは crossEra の記録だけになり
  「元帝と西晋の血のつながりが図に見えない」— 2026-08-21 ユーザー指摘）。
  客人の但し書きは章ページの `note` で名乗る

## 2. 縦軸と時代

- **縦は世代の段**（実時間スケールではない。在位が長い皇帝を縦棒にした失敗が起点）。
  時代感は「年の背骨」で段へ翻訳し、**家族の単位で枡の下限を揃える**。
  bucket の現行値: 秦漢 20・三国西晋 12・東晋十六国 10・南北朝 20/t30・隋唐 10/t100・
  五代十国 22（2026-08-21 の歴代君主4人追加後の再走査で 15→22）・宋遼西夏金 25/t100・
  元 12（同・20→12）・明 22/t100・清 25
- **背骨に繋ぐのは在位開始年か生年だけ。没年で繋がない** — 没年しか無い人（曹宇 278没）が
  「長生きした年」へ世代ごと引きずり下ろされ、兄弟の段揃えで一族が玉突きした（2026-08-19）
- **枡の幅 `bucket` は章ごとに実測で選ぶ**（`CHAPTERS` が持つ・秦漢 20・三国西晋 12・
  東晋十六国 10・南北朝 20・隋唐 10・五代十国 15・宋遼西夏金 25/thoroughness 100・元 20・
  明 22/thoroughness 100・清 25）。一律 20 だと三国西晋は交差 10 件、12 で 1 件 —
  章の年代密度で最適が大きく違う。新しい章では 10〜40 を一巡走らせて欠陥数の最少を採る。
  走査は `KINSHIP_ONLY=<eraId> KINSHIP_BUCKET=<N> node scripts/build-kinship-layout.mjs` —
  **`KINSHIP_ONLY` を付けないと他の章の JSON まで走査中の bucket で上書きされる**。
  **大きい章は elk の `thoroughness`（`CHAPTERS` の同名フィールド・既定7）も上げて走査する**
  （LAYER_SWEEP の反復数。南北朝は 7→30 で交差 20→13、隋唐は 100 で 5→3。ビルド時だけの
  コストなので遅くなってよい）
- **縦に長い別成分の時代合わせは、成分全体の年の中央値で上端を置かない** — 構成員ごとに
  「自分の年の段」との差を測り、その中央値で平行移動する。南北朝の実測: 北朝の成分
  （道武帝386〜北斉577・12世代）を中央値で置くと上端が年500の段に沈み、道武帝が
  劉裕（420）より2400px下に出た
- 別系統の小さい連結成分は、巨大成分の「段→年」を物差しに年の合う段へ平行移動する
- **時代の帯（6本・「前200年ごろ」）に数値の目盛りを引かない** — 段は世代の順なので
  年は数%前後する。境目はどのカードも跨がない切れ目からだけ選ぶ（規範の全文は
  site/AGENTS.md の同名の節。**精度を上げる方向で直さない**）

## 3. レイアウトの解き方（`site/scripts/build-kinship-layout.mjs`）

1. **家族ブロック**: 夫婦の鎖を1ノードに固める（elk に別ノードで渡すと隣接の保証が
   無い）。ブロック内は縦中央揃え・夫婦の間隔 24px。**相手が3人以上は demote で
   2人までに減らしてからブロック化する**（1節の規則）ので、throw（相手3人以上・鎖が輪）
   が出るのは demote の抜け漏れ — 出たら並びの規則を設計し直す
2. **ポート**: `FIXED_POS` で「子の下ろし点＝夫婦の間」「人へ入る線＝カードの真上」を
   座標で elk に渡す。ポート無しだと elk が縁の好きな場所から線を出し、家系図の文法が
   座標に残らない
3. **2回解く**: 1回目は年の背骨つきで**段の番号だけ**取る → 家族単位で段を揃える
   （下げる方向にだけ動かす）→ 2回目は背骨を捨て、段差を見えないスペーサで固定して
   線の形まで elk に引かせる
4. **`mergeEdges: true`**: 同じ下ろし点から出る兄弟の線を幹にまとめる。旧 union 方式では
   逆効果（交差増）だったが、ポート付き家族ブロックでは交差・高さ・ジグザグの全部が減る
5. **継承の線も elk に引かせる**（sideRoute でまっすぐ引くと司馬家のカードを突き抜けた）。
   下向き・**同段**（別々の家で枡がたまたま同じ＝元帝→晋武帝）はそのまま渡す — elk が
   1段割って前帝が上・後帝が下の時代の向きに揃う。**上向きは向きを逆にして渡し、出力で
   反転**。**両方向の対（簒奪⇄復位）は下向き側だけ渡し、上向き側は 12px 平行にずらした
   鏡写し**（ラベルは重なるので左右へ振り分ける）。ポートは**継承専用（カード中央+18px）**
   — Pb/Pt を使い回すと mergeEdges が家族の幹に束ね、朱の線が実線の上に重なる
6. **後処理**（この順。どれも「動かした先がカードに寄るなら諦めて監査に任せる」）:
   端をポートから付け根へ伸ばす → 折れ吸収（前後の短い区間を寄せる・union の端は横棒の
   幅ぶん動かせる）→ 兄弟バスの高さ揃え → **U字の折り返し除去**（枝ごと落とす形B →
   横棒を引き上げる形A の順）→ **兄弟の櫛の組み直し**（1人だけ早く曲がる兄弟を多数派の
   バスへ）→ **ひとり線の遠回りほどき**（兄弟の居ない線を「幹→廊下→垂下」の3折れへ）→
   **兄弟の幹の束ね**（同じ親の縦区間が12px以内で並走したら同じ x へ）→
   **廊下の重なりほどき**（別の親の横区間が重なったら、子が1人の側・短い側を数px ずらす）→
   **単独カードの中心合わせ**（親の下ろし点と子カードの中心が 56px までずれていたら
   **線ではなくカードを平行移動**して中心から中心へ落とす。1人ブロック・家族の入り1本
   だけが対象で、鏡写しの対に関わるカードは動かさない。採否は cost 合計に加えて
   交差・重なり・浮いた端・近すぎを**1件ずつ単独で**増やさないこと — cost の相殺で
   must-zero の欠陥が紛れ込んだ実測が根拠）→
   **大きめの折れの直線化**（56px までの Z 字を costOf 非悪化・重なり非増加のときだけ消す。
   **カードの端点は中心から 10px までしかずらさない** — それ以上は「カードの端から線が
   出る」不格好で、2026-08-19 に指摘された。大きいずれはカード側の平行移動＝中心合わせの
   持ち場）→ 鏡写しの作り直し → 小成分の時代合わせ・原点寄せ
   **端の x を動かす後処理（中心合わせなど）は、端の1点でなく端と同じ x の縦の連続
   区間ごと動かす** — 端点だけずらすと縦だった終端区間が**斜めの線**になる（全章で
   39箇所出ていた・2026-08-21 ユーザー指摘「不要な斜め線」。斜めの区間は交差・重なりの
   検査を静かにすり抜けるので、監査にも「斜めの区間」の欄があり **0 を保つ**）。
   **端の向きの不変条件**: 家族・継承の線はカードへ**必ず縦で**出入りする（横向きの端は
   カードの縁と同じ高さを走る形になり、自分の from/to との距離検査の除外をすり抜ける —
   文帝→劉武で顕在化・2026-08-19）。折れ吸収と直線化は「縦だった端を横へ変える寄せ」を
   不採用にし、elk が横で届けた端は「12px 手前の廊下＋垂下」へ曲げ直す。監査に
   「端の区間が横向き」の欄があり **0 を保つ**（この欄が立つ寄せは見かけ上交差を減らす
   ことがあるが、縁走りで隠れただけの偽の改善）
7. **経路を選び直すときの採点（costOf）は最後の監査と同じ物差しにする** — costOf が
   「同じ端を持つ線の交差」を数えていなかったとき、簡略化が親の下ろし線を2回またぐ継承を
   同点と誤認して採った（2026-08-19）

## 4. 機械の検査と目視

- レイアウト生成が数える欠陥: **カードどうしの重なり／二重線に見える並走（別親・x差
  10px以内・60px以上）／カードの中を通る／カードに近すぎる（12px）／端が浮いている／
  斜めの区間／不要な折れ（8px未満）は 0 を保つ**。線どうしの交差だけは混雑部で少数残ってよい
  （2026-08-19 現在: 秦・漢 1件・三国西晋 1件・東晋十六国 3件・南北朝 13件・隋唐 3件・
  五代十国 3件〔2026-08-21 の歴代君主4人追加＋bucket 15→22 の再走査で 3→2 → 同日の
  斜め線全廃で 3。増えた1件（閩の簒奪×家族の垂下）は前から視覚的には在った交差で、
  斜めの区間が検査の h/v 判定をすり抜けて数えられていなかっただけ〕・
  宋遼西夏金 3件〔宋の太祖の家族の混雑1・遼の世宗→穆宗まわり2。西遼の称制后2人を
  足しても不変〕・
  元 1件〔チンギス〜グユク・天元帝を足して bucket 20→12 に再走査。件数は据え置き〕・
  明 2件〔南明の推戴2本が永暦帝への家族の線をまたぐ。10〜22 が同数の最少〕・
  清 0件〔10〜40 のどの bucket でも0。唯一の欠陥ゼロ章〕。いずれも継承の線が行き先カードの家族の線をまたぐ形か、家族内の混雑。
  一時 11 件まで減って見えたのは端の縁走りで交差が隠れていた偽の改善。
  南北朝の 13 件は二桁だが、禅譲4本が王朝の家系樹をまたぐ章の構造によるもので、
  bucket・thoroughness の走査と時代合わせの直しを尽くした残り — 全部が直角の単純交差で
  読める。五代十国は thoroughness を上げても減らなかったので既定7のまま）
- `tools/shoot-kinship.mjs` が数える**カード内の字の切り詰めは全10章で 0 を保つ**
  （2026-08-21 ユーザー指示で、それまで許容していた5件〔隋唐1・元2・清2〕を
  `widthOf` の個別拡幅で全廃した。広がるのは入り切らないカードだけ — 全章で15枚・
  大半は +1〜3px・最大は文德順聖皇后長孫氏の +56px）

## 5. 操作の規則（決定済み）

- クリック＝個別ページへ遷移（`<a>` が静的HTMLに載る・`pointer-events-auto` 必須）
- **ホイール＝移動・拡大縮小は Ctrl/⌘＋ホイールかピンチ**（2026-08-19「拡大縮小は
  直感的な操作に反する」）
- 初期表示は章の入口の皇帝（秦・漢は前漢の高祖・zoom 0.7）。全体は MiniMap（政権色）で
- 図の外への移動は `translateExtent`（図＋160px）で止める。**図を動かすコードは
  d3 と同じ制約（`clampViewport`）を先に通す** — `setCenter` は制約を通らず、外れた
  座標に置くと次のドラッグ開始時に d3 が補正して画面が飛ぶ（2026-08-19）。余白込みの
  図が画面より狭い軸は d3 が中央固定にする点に注意（章の幅が縮むと顕在化する）
- 検索（名前の部分一致）と「政権へ移動」ボタン列を置く
- **凡例は「政権へ移動」の帯の右端の「凡例」ボタンから `<details>` のポップオーバーで
  開く（既定は閉じる・開いても図を押し下げない）**。政権ごとのカードの色見本は置かない
  （ボタン列と丸ごと重複）。**h1 は全章共通の「系譜図」・章名はセグメントコントロールの
  押下状態と `<title>` が名乗る** — 章名を h1 にするとその幅でタブ列の位置がページごとに
  ずれる（いずれも 2026-08-19 ユーザー指示。皇帝数・親族数の説明文も不要と判断され削除）
