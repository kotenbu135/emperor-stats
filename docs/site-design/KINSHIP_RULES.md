秦・漢の章（105人）で 2026-08-19 にユーザーの「概ね良い」まで到達した形を、
**次の章（三国西晋 → 東晋十六国 → 南北朝 → 隋唐 → 五代十国）を同じ品質で作るための規範**
として書き残す。ビルドが落ちる契約は [site/AGENTS.md](../../site/AGENTS.md) の「系譜図」節が正。
取り下げた2版の失敗（2026-07-24・2026-08-17）は SITE_DESIGN.md と Issue #174 に残っている。
見た目の見本は `docs/site-design/kinship-refs/`（**形の見本は B = UsefulCharts**。
A = ハプスブルクは肖像カードと章ナビの見本）。

## 1. 図の文法 — 「一般的な家系図のつなぎ方」（2026-08-19 ユーザー指示）

- **夫婦は必ず隣に並べ、カード中央の高さの横棒で結ぶ。** 複数婚は鎖
  （呂雉—高帝—薄姫）。**結び目の点は描かない**（黒点は 2026-08-19 に廃止）
- **子は夫婦の横棒から T 字に下ろす。** 下ろし点は夫婦の間（横棒の上ならどこでも
  よい — 中央に固定しない）。兄弟は1本の幹 → 1本の横バス → 各自へ垂下の櫛にする
- **片親しか確定していない子は親のカードの真下の縁から直接下ろす**
- 線種（実装は `chapter-flow.tsx` の `EDGE_STYLE` が唯一の正・凡例はそこから導出）:
  | 線 | 見た目 |
  |---|---|
  | 夫婦の横棒・実の親子 | 実線 1.9px |
  | 実母だけ確定 | 破線 5 4 |
  | 養親 | 一点鎖線 12 4 2 4 ＋ 線上に「養母／養父」ラベル |
  | 実父の異説（呂不韋型） | 点線 1 4・幅2 の夫婦横棒（記号は重ねない） |
  | 継承（禅譲・簒奪・復位・推戴・自立・内禅） | 朱の破線 6 4 ＋ ラベル ＋ 矢印 |
- **引かない線**: `enthroned`（擁立）・`hereditary`（世襲・家系の線と重複）・
  `remote-ancestor`（段が飛ぶ）。親子で既に結ばれた2人の継承線も引かない
- **カード**: 皇帝 = 112×140（上半分は肖像。無い人は政権色の印章面＋姓1字）＋政権色帯。
  親族 = 名前と年の帯だけ（38px・名前に補足がある人は50px）・男女2色。
  **親族の左端 4px に「その家の政権」の色**を立てる（家族の線で最寄りの皇帝から写す。
  帯そのものを政権色にすると男女の区別と白文字 4.5:1 が崩れるので縁の1本にとどめる）
- **収録**: 章（eraId）の皇帝＋親族＋**客人**。**章内に線が1本も無い人物は図から外して**
  `generatedFrom.dropped` に記録する。章をまたぐ親子は `crossEra` に記録
- **客人**（章の eraId でないが出す人物・`CHAPTERS` の `guests`）は2種類だけ:
  (a) **禅譲の前帝**（後漢の献帝→魏。「だけ」入れる — 前帝の家族は連れて来ない）、
  (b) **前の章で「線が1本も無い」として外した親**（袁逢・劉弘。子がこの章にいる）。
  客人の但し書きは章ページの `note` で名乗る

## 2. 縦軸と時代

- **縦は世代の段**（実時間スケールではない。在位が長い皇帝を縦棒にした失敗が起点）。
  時代感は「年の背骨」で段へ翻訳し、**家族の単位で枡の下限を揃える**
- **背骨に繋ぐのは在位開始年か生年だけ。没年で繋がない** — 没年しか無い人（曹宇 278没）が
  「長生きした年」へ世代ごと引きずり下ろされ、兄弟の段揃えで一族が玉突きした（2026-08-19）
- **枡の幅 `bucket` は章ごとに実測で選ぶ**（`CHAPTERS` が持つ・秦漢 20・三国西晋 12）。
  一律 20 だと三国西晋は交差 10 件、12 で 1 件 — 章の年代密度で最適が大きく違う。
  新しい章では 10〜40 を一巡走らせて欠陥数の最少を採る
- 別系統の小さい連結成分は、巨大成分の「段→年」を物差しに年の合う段へ平行移動する
- **時代の帯（6本・「前200年ごろ」）に数値の目盛りを引かない** — 段は世代の順なので
  年は数%前後する。境目はどのカードも跨がない切れ目からだけ選ぶ（規範の全文は
  site/AGENTS.md の同名の節。**精度を上げる方向で直さない**）

## 3. レイアウトの解き方（`site/scripts/build-kinship-layout.mjs`）

1. **家族ブロック**: 夫婦の鎖を1ノードに固める（elk に別ノードで渡すと隣接の保証が
   無い）。ブロック内は縦中央揃え・夫婦の間隔 24px。**相手が3人以上・鎖が輪になったら
   throw する**（データが増えたとき黙って崩れないため。出たら並びの規則を設計し直す）
2. **ポート**: `FIXED_POS` で「子の下ろし点＝夫婦の間」「人へ入る線＝カードの真上」を
   座標で elk に渡す。ポート無しだと elk が縁の好きな場所から線を出し、家系図の文法が
   座標に残らない
3. **2回解く**: 1回目は年の背骨つきで**段の番号だけ**取る → 家族単位で段を揃える
   （下げる方向にだけ動かす）→ 2回目は背骨を捨て、段差を見えないスペーサで固定して
   線の形まで elk に引かせる
4. **`mergeEdges: true`**: 同じ下ろし点から出る兄弟の線を幹にまとめる。旧 union 方式では
   逆効果（交差増）だったが、ポート付き家族ブロックでは交差・高さ・ジグザグの全部が減る
5. **継承の線も elk に引かせる**（sideRoute でまっすぐ引くと司馬家のカードを突き抜けた）。
   下向き・**同段**（別々の家で枡がたまたま同じ＝元帝→晋武帝）はそのまま渡す — elk が
   1段割って前帝が上・後帝が下の時代の向きに揃う。**上向きは向きを逆にして渡し、出力で
   反転**。**両方向の対（簒奪⇄復位）は下向き側だけ渡し、上向き側は 12px 平行にずらした
   鏡写し**（ラベルは重なるので左右へ振り分ける）。ポートは**継承専用（カード中央+18px）**
   — Pb/Pt を使い回すと mergeEdges が家族の幹に束ね、朱の線が実線の上に重なる
6. **後処理**（この順。どれも「動かした先がカードに寄るなら諦めて監査に任せる」）:
   端をポートから付け根へ伸ばす → 折れ吸収（前後の短い区間を寄せる・union の端は横棒の
   幅ぶん動かせる）→ 兄弟バスの高さ揃え → **U字の折り返し除去**（枝ごと落とす形B →
   横棒を引き上げる形A の順）→ **兄弟の櫛の組み直し**（1人だけ早く曲がる兄弟を多数派の
   バスへ）→ **ひとり線の遠回りほどき**（兄弟の居ない線を「幹→廊下→垂下」の3折れへ）→
   **兄弟の幹の束ね**（同じ親の縦区間が12px以内で並走したら同じ x へ）→
   **廊下の重なりほどき**（別の親の横区間が重なったら、子が1人の側・短い側を数px ずらす）→
   鏡写しの作り直し → 小成分の時代合わせ・原点寄せ
7. **経路を選び直すときの採点（costOf）は最後の監査と同じ物差しにする** — costOf が
   「同じ端を持つ線の交差」を数えていなかったとき、簡略化が親の下ろし線を2回またぐ継承を
   同点と誤認して採った（2026-08-19）

## 4. 機械の検査と目視

- レイアウト生成が数える欠陥: **カードどうしの重なり／二重線に見える並走（別親・x差
  10px以内・60px以上）／カードの中を通る／カードに近すぎる（12px）／端が浮いている／
  不要な折れ（8px未満）は 0 を保つ**。線どうしの交差だけは混雑部で少数残ってよい
  （2026-08-19 現在: 秦・漢 1件・三国西晋 1件）
- **「監査 0件」を見た目の根拠にしない**（2026-08-18 の外部レビュー13件は全部監査の外）。
  `npm run build && node tools/shoot-kinship.mjs` で**全タイルを自分の目で見る**。
  目視の観点はユーザー指摘に由来する5つ: つなぎ方が家系図の文法か／線が多く見えないか／
  二重線に見える並走が無いか／カードが被っていないか／不要な曲がりが無いか
- 操作は Playwright で実測する: カードをクリック → `/emperors/<id>` へ遷移・
  ホイールで縦パン・Ctrl/⌘＋ホイールで拡大縮小・ドラッグでパン（パン後に誤遷移しない）・
  **図の縁＋160px で止まる**（`translateExtent`）

## 5. 操作の規則（決定済み）

- クリック＝個別ページへ遷移（`<a>` が静的HTMLに載る・`pointer-events-auto` 必須）
- **ホイール＝移動・拡大縮小は Ctrl/⌘＋ホイールかピンチ**（2026-08-19「拡大縮小は
  直感的な操作に反する」）
- 初期表示は章の入口の皇帝（秦・漢は前漢の高祖・zoom 0.7）。全体は MiniMap（政権色）で
- 図の外への移動は `translateExtent`（図＋160px）で止める。**図を動かすコードは
  d3 と同じ制約（`clampViewport`）を先に通す** — `setCenter` は制約を通らず、外れた
  座標に置くと次のドラッグ開始時に d3 が補正して画面が飛ぶ（2026-08-19）。余白込みの
  図が画面より狭い軸は d3 が中央固定にする点に注意（章の幅が縮むと顕在化する）
- 検索（名前の部分一致）と「政権へ移動」ボタン列を置く

   載せない（`robots` は `index: false` のまま）
