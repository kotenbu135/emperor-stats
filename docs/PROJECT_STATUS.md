西梁 後主 琮「孝靖帝」（舊唐書 蕭銑伝）で、どちらも**閉域がその政権の書1冊**だった。
**諡を贈った主体が別政権**（王琳＋北齊／從子 蕭銑）なので、条はその政権の書に在る。
段の `read-absent` 177件は同じ形で閉じているので残量表に行を立てた
（標本12件では反例0だが、**実欠陥2件はどちらも標本の外**。次は母集団を
「亡国・廃位して別政権に諡を贈られうる君主」へ絞る）。
**この回の道具の教訓**: 閉域は「書1冊の授与条を全数走査」と「本人の紀を全長諡の各字＋帝で
当て直し」の**2本立てで、片方では取りこぼす**（前者だけだと地の文の呼称が落ち、
後者だけだと他人へ贈った条が見えない）。**生前の尊号との分離は語ではなく条の位置で決まる**
（宋史は譲位後の孝宗を「壽皇聖帝」と呼ぶが諡ではない）。
7と9は**器が無いまま量だけが残っている**ので、続けるなら先に器（後継 Issue か残量表の行）を立てる。

## 史料解釈の方針

- **原典（正史の本紀・列伝）を一次情報とする**。ただし史書自体が恣意的に書き換えている可能性がある（易姓革命後の正典編纂で前王朝最後の皇帝が実際以上に悪く描かれるなど）ため鵜呑みにしない
- **原典と学術的通説が対立する場合**は原典をベースに有力な異説を `note`／`verification.notes` へ併記するか `諸説あり` と記録する。単なる俗説・二次創作は採用しない。迷う場合はユーザーに確認する
- **法医学調査・考古学的出土品調査など客観的物証がある場合**は例外的に重視する（都度ユーザーに確認してから採用）
- **カテゴリ値には「不詳／諸説あり」の区分がある**。無理に二択で決めつけない
