# 姓と諱を別の欄に分ける（Issue #37 単位6・2026-08-03）

`name.personalName` が持っていた**姓＋諱**（「嬴胡亥」）を、`name.familyName`（姓）と
`name.personalName`（諱）へ分ける。**2026-08-03 に決めた「姓を別欄に分けない」を
同じ日に見直したもの**で、経緯を残すためにこの紙を立てる。

## 1. なぜ戻したか

分けない側の決定は「保存の形」だけを見ていた。実際に配布・表示すると、**同じ欄が3か所で
「諱」を名乗っている**のに中身は姓＋諱、という状態が残っていた:

| 名乗り | 実体 |
|---|---|
| `docs/schema/SCHEMA_OVERVIEW.md`「`personalName`: 諱」 | 姓＋諱 |
| `meta.catalogs.ethnicNameKinds[manchu].counterpartLabel = "諱"` | 姓＋諱（愛新覚羅載湉） |
| 個別ページの名前チップ「諱 嬴胡亥」（336人） | 姓＋諱 |

紹介文だけは Issue #47（2026-08-03）で「**諱と書くときは姓を外す**」へ揃っていた
（[WRITER.md](../process/profile-writing/WRITER.md) の該当行）。つまり**同じ問題を一度
文章側だけで直しており、データと画面が取り残されていた**。ユーザー指摘は個別ページの
「諱 嬴胡亥」で、**表示のラベルではなくスキーマ定義の問題**として直す判断（2026-08-03）。

分けたほうが原典に近いことも絞り込みで出た — **「嬴胡亥」という連結形はコーパスに0件**
（「胡亥」は2537件）。姓＋諱の連結は近代の呼び方で、正史は「姓◯氏，讳◯」と分けて書く。

## 2. 欄

```json
"name": {
  "familyName": "嬴",
  "personalName": "胡亥"
}
```

- **`familyName`** … 姓（複姓を含む）。`null` は「**姓を持たない形で伝わる**」で、
  未記入ではない。該当はモンゴル語名の漢字音写12人（元11・北元1。「忽必烈」は姓ではない）
- **`personalName`** … 諱（姓を含まない）。**意味が変わる欄**なので、移行前の値は
  `data/internal/family-name-split-originals.json` に凍結する

`ethnicName.value`（契丹名・女真名）は**姓を冠したまま据え置く**（「耶律堯骨」）。
遼史・金史がその形で載せており、こちらを割る根拠を持っていない。

## 3. 主張と検査

| 主張 | 検査 |
|---|---|
| A 型 | `familyName` は1〜4字の漢字か `null`、`personalName` は非空 |
| B 分割の同一性 | `familyName + personalName` が凍結標本の移行前値に戻る（**字を落とす・順を変える形を落とす唯一の検査**） |
| C `null` の所在 | `familyName` が `null` なのは宣言済み政権（`yuan`・`northern-yuan`）だけ。**その政権は全員 `null`** |
| D 政権内の一貫性 | 同じ `regimeId` の `familyName` は1種類。割れてよいのは宣言済みの4政権だけ（北魏 拓跋/元・西魏 元/拓跋・後周 郭/柴・安史の燕 安/史） |
| E 底本照合 | 姓が「姓〈姓〉氏」の形で底本に在る／諱が「讳〈諱〉」で本人の原文に在る（**ラチェット**） |

A〜D は `validate_emperors.py::check_family_names`（CI・コーパス不要）、E は
`verify_quotes.py --check-family-names`（ローカル専用・要コーパス）。検出力テストは
`scripts/test_family_name.py`。

**D が主力**。誤分割は姓を1字ずらすので、政権のうち1人だけを間違えると必ず割れる。
**逆に政権まるごと同じ誤り方をする形（一覧に無い複姓を全員1字で切る）は D では見えない**ので、
そこは絞り込み側の `ambiguous` 検出器（2字接頭辞が複姓として当たるか）が受け持つ。

## 4. 切れ目の根拠（絞り込み）

`scripts/screens/family_name_split.py`・記録は `data/screenings.json` の
`family-name-split-issue37`。**母集団365人 → 要読解0人**。

| バケット | 件数 | 何で切れ目を支えているか |
|---|---:|---|
| `kana-name` | 12 | `ethnicName.kind == mongol`（姓を持たない） |
| `hui` | 164 | 本人の原文が「讳〈諱〉」と書いており**切れ目を名指ししている** |
| `xing` | 189 | 姓候補が「姓〈姓〉氏」でコーパスに実在（複姓を1字で切る形はここで落ちる） |
| `ambiguous` | 0 | 1字で切った95種の2字接頭辞が複姓として当たるか — 0件 |
| `unattested` | 0 | — |

**`xing` の189人は「この人物がその姓であること」を機械で確かめていない**（姓の実在だけ）。
そこは政権の姓という既知の事実に寄りかかっている。標本監査は6件・反例0件で、
`qin-er-shi`（連結形が原典に0件）と `shiguo-nanhan-liuchang`（`hanzi_norm` が「鋹」を
「𬬮」へ変換して照合が0件になる）の2件が副産物として出た。

## 5. 表示（サイト）

- 名前チップは「**諱 胡亥**」＋「**姓 嬴**」の2行になる
- h1 の脇の補助名は**姓＋諱の派生値**のまま（「武帝 劉徹」で人物が特定できる形を崩さない）。
  清の11人だけ姓を落とす既存の分岐は、`personalName` が諱だけになったので**分岐そのものが消える**
- モノグラム（肖像が無い人物の一文字）は `familyName` の頭文字。`null` の12人は通用名の頭文字
- 一覧の検索文字列は姓＋諱・諱の両方を含める（「劉徹」でも「徹」でも当たる）

## 6. 決めないこと

- **秦の `familyName` を「嬴」と「趙」のどちらにするか**。史記 秦始皇本紀は
  「及生，名為政，姓趙氏」で、先秦では男子は氏を称し姓（嬴）を名に冠さない。
  一方コーパスには「姓嬴氏」も151件在る。**切れ目とは別の問い**なので、この移行では
  現行値（嬴）のまま分けるだけにする（2026-08-03 ユーザー判断）
- **`ethnicName.value` の姓**（耶律堯骨の「耶律」）。据え置く（2節）
