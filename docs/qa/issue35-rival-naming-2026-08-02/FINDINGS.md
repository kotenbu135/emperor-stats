## 2. `rival` の定義 ― 「並立」だけでは4人が説明できない

Issue の主張は「実際に効いている基準は帝紀の有無ではなく、在位が先代と並立しているか逐次か」。
20人全員について、同じ `regimeId` の `regular` な皇帝と在位期間が重なるかを機械照合した。

**結果: 並立16人 / 逐次4人。**

| | 人物 |
|---|---|
| 並立（16人） | 元凶劭・劉子勛・蕭正徳・蕭紀・拓跋余・幼主元釗・元曄・元愉・元法僧・元顥・高延宗・楊浩・李裕・李承宏・李熅・朱友珪 |
| **逐次（4人）** | **蕭淵明**・蕭荘・高紹義・恭帝侗（皇泰主） |

逐次の4人のうち3人は「**王朝の帝統が絶えた後に、亡命先や残存勢力で帝号を称した**」で括れる。

- 蕭荘 558–560: 梁は557年に陳へ禅譲して滅亡済み。北斉・王琳の下で称した
- 高紹義 577–580: 北斉は577年に北周に滅ぼされた後、突厥に亡命して称した
- 恭帝侗（皇泰主）618–619: 恭帝侑が618年6月に唐へ禅譲した10日後に洛陽で称した

**残る蕭淵明1人だけが、王朝が健在なまま在位が逐次**（元帝の崩御 555-01-27 と敬帝の即位 555-10-29 の
すき間に入る 555-08-30〜10-27）。つまり並立基準を単独で採ると蕭淵明は `regular` になり、
現行データと食い違う。

### 提案する定義文

「並立」を唯一の基準に据え替えるのではなく、**正統な帝統の外側で帝号を称したこと**を本体にして、
並立と亡命・残存政権を例示に落とす。帝紀の有無は判定基準ではなく傍証だと明記する。

> `standing`：`regular`（その政権の歴代皇帝）／`rival`（同じ政権の正統な帝統の外側で帝号を称した
> 対立・僭称の皇帝。多くは在位が歴代皇帝と並立するが、王朝の帝統が絶えた後に亡命先・残存勢力で
> 称した例も含む）。**その人物の位置づけ**を表します。正史が帝紀を立てているかは傍証として
> 参照しますが、判定基準そのものではありません（傀儡でも帝紀を持たない蕭棟は `regular`）。

Issue が指摘する「同じファイルの中で `category` からは正統論を追い出しておきながら
`standing` の定義文が帝紀基準を拾っている」という矛盾は、この書き換えで解消する。

## 3. 蕭淵明の `standing` は `rival` のまま ―「閔帝」の出所は王琳の追諡

日本語版 Wikipedia が蕭淵明を「閔帝・貞陽侯（在位555年）」として梁の歴代6番目の本表に入れている
根拠を探したところ、**「閔帝」は北齊書 巻33（蕭荘の記事）にあった**。

> 梁将王琳在江上与霸先相抗，显祖遣兵纳梁永嘉王萧庄主梁祀。九年二月，自湓城济江，三月，即帝位于郢州，
> 年号天启，王琳总其军国，**追谥明曰闵皇帝**。

つまり**閔皇帝の諡を贈ったのは、蕭荘を立てた王琳の陣営**（558年）であって、梁の朝廷ではない。
梁書・南史・資治通鑑には「閔帝」の語は無く（南史・資治通鑑の「闵帝」は北周閔帝）、
三書とも一貫して「貞陽侯（南史は避諱で蕭明）」と呼び、帝紀を立てない。

- 南史 巻8「七月辛丑，僧辩纳贞阳侯萧明，自采石济江。甲辰，入建邺。丙午，**即僞位**。年号天成，
  以帝爲皇太子」
- 梁書 巻6「九月甲辰，司空陈霸先举义，袭杀王僧辩，**黜萧渊明**。丙午，帝即皇帝位」
- 廃位後は「以贞阳侯渊明为司徒，封建安郡公」→「太傅建安公渊明薨」で、皇帝としては扱われない

**皇帝としての承認が、彼を擁立した北斉・王琳の側からしか出ていない**（しかも諡は3年後の追贈）。
蕭正徳が通説でも歴代に数えられないのと事情は違うが、原典基準では `rival` のままが妥当と判断する。

一方、**在位が逐次である事実は上の2で定義文に反映が要る**（蕭淵明は並立基準の唯一の例外）。

### 名前データ側への申し送り

`NAME_DISPLAY_PLAN_2026-08-02.md` 5節（諡号・廟号を全365人に埋める作業）で蕭淵明を扱うときは、
**`posthumousName` に「閔皇帝」を入れるなら、贈り主が王琳陣営であることを `note` に必ず残す**。
梁の朝廷の諡と同列に並べると、`standing: rival` の判断根拠と矛盾して見える。
