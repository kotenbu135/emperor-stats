## tools/

Playwright のスクリプト群。`site/` から実行する（playwright はそこにしか解決しない）。
出力先の `rebuild-shots/`・`palette-shots/` などは `.gitignore` 対象（ローカル専用）。
`_` で始まるファイルも `.gitignore` 対象で、使い捨ての計測スクリプトはその名前で置く。
