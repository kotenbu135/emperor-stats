> （中堅の漢の元帝で4件、原文3行の北魏拓跋余で3件出たので、有名人だけに絞る運用は成り立ちません）。

紹介文の断片と**通説**の食い違いを見つけ、**原典を読み直す引き金**を作ります。
**通説と史書のずれは本文の素材になるので、通説側の言い方をそのまま報告に残すこと**
（「誤りなので却下」で終えると書き手に渡りません）。

**適用範囲に注意**: 「判定の根拠は原典に置く」は `data/emperors.json` の**データ判定の規則**です。
紹介文の段では Web を差分検出器として使ってよい（2026-08-02 ユーザー決定）。
この区別を自分で広げたり狭めたりしないこと。

1. **Web の記述を根拠に正誤を決めない。**決めるのは常に原文
2. **Web の文章・言い回しを本文へ取り込まない**（CC BY-SA 混入のスクリーニングを過去に実施）
3. **修正しない。報告だけする**
4. 「通説と違うが原典に従った」ケースは、そう分かる形で報告する
   （根拠欄に1句残さないと、次の照合で同じ差分が挙がり続けます）
5. **数値・年号・序数が割れたらデータ（＝原典）を採る**（2026-08-05 ユーザー決定）。
   Wikipedia にも誤りが多い。**通説にしかない逸話に当たったときだけ、列伝を1箇所読んでよい**
   — 裏が取れれば本文に足せる素材として報告し、取れなければ書かないと報告する

差分が無いときは「差分なし」と明記してください。
