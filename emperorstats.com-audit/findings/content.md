## 指摘一覧

### 1. [High] 著者・運営者情報が構造化データ上も本文上も一切存在しない

**証拠**:
- `site/out/about.html` の Dataset JSON-LD:
  ```json
  "creator": { "@type": "Organization", "name": "中国皇帝統計" }
  ```
  `sameAs` フィールドなし。個人名・法人名・所在地・連絡先メールアドレスの記載なし。
- `site/out/` 直下に `privacy` `contact` `terms` に該当するページは存在しない（`ls site/out/ | grep -iE "privacy|contact|terms|policy"` → 該当0件）。
- 連絡経路は `about.html` 本文中の「GitHubのIssue」リンク（`https://github.com/kotenbu135/emperor-stats/issues`）のみ。

**影響**: Authoritativeness/Expertiseの評価基盤（誰が書いたか・検証可能な実在性）が構造化データからも本文からも取れない。学術寄りデータセットサイトとしては、著者不明は信頼性シグナルとして明確なマイナス。

**修正案**: 少なくとも Dataset/Organization の `sameAs` に GitHub リポジトリ・GitHub プロフィールURLを追加し、`about.html` 本文にも運営体制（個人プロジェクトであること自体は問題ないが、その旨の明記）を追加する。実名開示が難しい場合も、GitHubアカウントという「検証可能な連続的活動履歴」を紐付けるだけでゼロよりは大きく改善する。

**失敗判定**: 別の場所（現状未確認のページ・meta タグ等）に運営者情報がすでに存在していた場合はこの指摘は誤り。今回の調査は `site/out/` 全378ファイルではなく主要ページ・全emperor個別ページの `<main>`/`<script type="application/ld+json">` を機械的に走査した結果であり、未走査箇所に記載がある可能性はゼロではない。

**先行指標**: 次回監査で Dataset/Organization JSON-LD に `sameAs` が追加されているか、`about.html` に運営者に関する記述が増えているかを diff で確認できる。

### 2. [Medium] AI活用・非専門家である旨の開示は「諸刃の剣」——透明性はプラスだがExpertiseシグナルを直接押し下げる

**証拠**: `about.html` 本文（免責事項セクション）
> 「本サイトは、AI（大規模言語モデル）を活用して調査・集計・構築しています。また、制作者は歴史学の専門家ではありません。」

**評価**: 2025年9月版QRGの立場では、AI利用の明示的開示自体はTrustworthinessに資する誠実な行為であり隠すべきではない。一方で「専門家ではない」という自己申告は、資格ベースのExpertiseシグナルを構造的に持てないことを意味する。本サイトはこれを、原典（正史本紀・列伝）への悉皆的な遡及調査という「方法論的厳密性」で代替しようとしている構成になっており、この方針自体は妥当だが、現状はその代替シグナルが `/about` 以外の場所（各統計ページ等）にはほとんど露出していない。

**修正案**: 監修者・レビュー体制を追加できるならそれが最善。追加が難しい場合は、「原典一次資料への遡及率100%」「暦換算に使用したライブラリ（sxtwl）とその検証方法」など、既に`/about`にある方法論的信頼性の記述を、統計ページ側にも要約リンクとして露出させる（指摘9・11とも関連）。

**失敗判定**: 今後、監修者クレジットや査読プロセスの記載が追加されれば解消される。

**先行指標**: `about.html` の当該文言周辺に監修・レビュー体制の記述が追加されるか。
